### O Operador de Atribuição
### Em JavaScript, o sinal igual () é um operador de atribuição, não um operador igual a =
### Isso é diferente da álgebra. O seguinte não faz sentido em álgebra:
### x = x + 5
### No JavaScript, no entanto, faz todo sentido: ele atribui o valor de x + 5 a x.
### (Ele calcula o valor de x + 5 e coloca o resultado em x. O valor de x é incrementado por 5.)
### O operador igual a é escrito como no JavaScript ==

### Aritmética em JavaScript
### Assim como na álgebra, você pode fazer aritmética com variáveis JavaScript, usando Operadores como e : =+
### let x = 5 + 2 + 3;
### Você também pode adicionar strings, mas as strings serão concatenadas:
### let x = "John" + " " + "Doe";
### let x = "5" + 2 + 3;
### let x = 2 + 3 + "5";
### Se você colocar um número entre aspas, o restante dos números será tratado como cadeias e concatenado.
